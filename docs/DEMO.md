# Demo script (about 2 minutes)

**Before recording:** open https://jarvis-mobile-backend.onrender.com/api/health once (wakes the free tier), laptop backend off,
phone volume up, Do Not Disturb on, screen recording on, "Hey Jarvis" service running. Do one dry run of every step.
Use a friend's number or a contact you made for the demo; clear the memory first ("forget everything").

| Time | Say / do | What the viewer should see |
|---|---|---|
| 0:00 | Voiceover: "Siri and Bixby run commands. JARVIS takes a goal and figures out how to do it." | Phone home screen |
| 0:10 | "Hey Jarvis, what's the temperature in Boston?" | Panel glows, card appears with °C and °F, spoken reply. Nothing about the process is shown. |
| 0:25 | "Hey Jarvis, text Mom." Answer its questions: the message, then WhatsApp. | Multi-turn conversation, then a sent message |
| 0:50 | "Hey Jarvis, set an alarm for 7 AM, text mummy on WhatsApp that I'm running late, and add dinner at 7 PM tomorrow to my calendar." | **Mission Mode:** three actions, one spoken summary. Show the alarm, the chat and the calendar entry afterwards. |
| 1:15 | Open a chat or web page, "Hey Jarvis, summarize this", then "add this to my calendar" on a page with a date. | Screen-aware: answers about what is on screen |
| 1:35 | "Hey Jarvis, remember mummy is always on WhatsApp", then "text mummy hello". | No question about which app (memory, on device) |
| 1:45 | "Hey Jarvis, turn on battery saver." | Status pill "Working on it", the hidden agent operates Settings, then a spoken result |
| 2:00 | Show a confirmation prompt (payment-style screen or a Send), tap Deny. | Safety gate quotes what is on screen |
| 2:10 | Voiceover: "Muse Spark reasons and sees, Muse Voice transcribes, SAM 3.1 finds icons. Contacts never leave the phone." | README or architecture diagram |

**If something fails live:** keep recording and re-run; never edit in a result that did not happen. If the wake word does not fire,
say "Hey Jarvis" once more, clearly, and wait for the glow before speaking.
